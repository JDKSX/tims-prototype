## ที่มาของไฟล์

ไฟล์ในรีโปนี้เป็น **สำเนา** จากรีโปหลักของโปรเจกต์ (`design/`) เอามาไว้ที่นี่เพื่อให้เปิดดูผ่านเว็บได้เท่านั้น

```
index.html   ← สำเนาของ design/Prototype_TIMS.html
fonts/       ← ฟอนต์ที่ฝังมากับหน้า (Trirong · IBM Plex Sans Thai)
logos/       ← ตรามหาวิทยาลัยและตราคณะ
sync.sh      ← สคริปต์คัดลอกของใหม่จากรีโปหลักมาที่นี่
```

**เร็ว ๆ นี้** — ตัวปรับแต่งโลโก้ระบบและมาสคอต **"น้อง TIMS"** (กำลังออกแบบอยู่)
จะเพิ่มเข้ามาที่ `logo.html` เพื่อให้ทีมงานช่วยกันเลือกแบบ ·
ในต้นแบบกันที่ไว้ให้มาสคอตแล้วที่หน้าเข้าสู่ระบบฝั่งซ้าย

**การแก้ไขทั้งหมดทำที่รีโปหลัก** แล้วค่อยคัดลอกมาที่นี่ (`bash sync.sh`) — ห้ามแก้ไฟล์ในรีโปนี้โดยตรง เพราะจะถูกเขียนทับรอบถัดไป
